# codicon.css

A CSS project for codicon icon styling.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Cleanskiier27/codicon.css.git
cd codicon.css
```

### Setup

Link your local repository to GitHub:

```bash
git remote add origin https://github.com/Cleanskiier27/codicon.css.git
git branch -M main
git push -u origin main
```

## CI/CD

This project uses GitHub Actions for continuous integration and deployment. Workflows are defined in the `.github/workflows` directory.
