# codicon.css

A CSS project for codicon icon styling.

## Usage

### Pure CSS icons

```html
<span class="icon icon-home"></span>
```

### Imported SVG icons

SVG assets in `/assets/svgs` can be used through CSS classes:

```html
<span class="icon icon-svg icon-svg-home"></span>
<span class="icon icon-svg icon-svg-search"></span>
```

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Cleanskiier27/codicon.css.git
cd codicon.css
```

### Setup

Link your local repository to GitHub:

```bash
git remote add origin https://github.com/Cleanskiier27/codicon.css.git
git branch -M main
git push -u origin main
```
